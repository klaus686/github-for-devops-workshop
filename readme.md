# 🚀 GitHub for DevOps Workshop

Welcome to **GitHub for DevOps Workshop**!

This repository contains my hands-on learning and practice with Git and GitHub, focusing on the fundamentals required for a DevOps Engineer.

The goal of this repository is to understand version control, manage source code, practice Git commands, and explore GitHub features used in real-world development and DevOps workflows.

If you are a beginner learning Git and GitHub, feel free to explore, practice, and learn along with me!

Through this workshop, I am practicing:

- Understanding Git and Version Control Systems (VCS).
- Creating and managing Git repositories.
- Working with Git commands.
- Tracking changes and managing files.
- Understanding staging and commits.
- Working with branches and switching between branches.
- Connecting local repositories with remote GitHub repositories.
- Pushing and pulling code between local and remote repositories.
- Exploring GitHub Actions and workflow automation.
- Understanding basic collaboration workflows.

## 💻 Important Git Commands

| Command | Description |
|---|---|
| `git init` | Initialize a Git repository |
| `git status` | Check repository status |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Commit changes |
| `git log` | View commit history |
| `git log --oneline` | View compact commit history |
| `git branch` | List branches |
| `git branch branch-name` | Create a branch |
| `git switch branch-name` | Switch branches |
| `git remote -v` | View remote repositories |
| `git push origin main` | Push changes to GitHub |
| `git pull origin main` | Pull changes from GitHub |

For additional commands and explanations, check **git_commands.txt**.

## ⚙️ Getting Started

Follow these steps to practice the repository locally.

**1. Clone the repository**

```bash
git clone https://github.com/klaus686/github-for-devops-workshop.git
```

**2. Navigate to the project**

```bash
cd github-for-devops-workshop
```

**3. Check repository status**

```bash
git status
```

**4. Explore the Git command notes**

```bash
cat git_commands.txt
```

**5. Create a new branch for practice**

```bash
git switch -c my-practice-branch
```
